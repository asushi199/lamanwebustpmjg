# Portal Digital USTP Manjung

Portal rasmi yang menyatukan akses ke OSC USTP, Direktori GPICT/GP DELIMa/GPM dan Sistem Tempahan Bilik PKG Daerah Manjung.

## Teknologi

- Next.js 16 (App Router)
- React dan TypeScript
- CSS responsif tanpa pangkalan data atau API tambahan

## Arahan

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run test
npm.cmd run lint
npm.cmd run build
```

## Deployment

Projek direka untuk Vercel dan tidak memerlukan environment variable.
