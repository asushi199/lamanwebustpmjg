# Project Guidance

- Semua teks awam hendaklah menggunakan Bahasa Melayu rasmi.
- Kekalkan portal sebagai pintu masuk ringan; jangan gabungkan pangkalan data atau log masuk sistem sasaran.
- Semua URL perkhidmatan mesti ditakrifkan sekali sahaja dalam `src/lib/portal-data.ts`.
- Utamakan telefon, kebolehcapaian papan kekunci dan `prefers-reduced-motion`.
- Jangan paparkan status sistem tanpa pemeriksaan sebenar.
- Sebelum selesai, jalankan `npm.cmd run test`, `npm.cmd run lint`, `npm.cmd run typecheck` dan `npm.cmd run build`.
